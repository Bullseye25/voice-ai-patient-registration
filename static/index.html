CareCloud API Endpoints & Developer Reference

All endpoints strictly follow standard HTTP status codes (200, 201, 400, 404, 422, 500) and return unified JSON envelopes: { "data": {...}, "error": null }.

Open Swagger UI ReDoc Spec openapi.json
GET /patients List Patients

Retrieves all registered patient records. Supports query parameters for filtering by ?last_name=, ?phone_number=, ?date_of_birth=, and ?include_deleted=true. Automatically reconciles with Supabase Cloud.

GET /patients/{patient_id} Retrieve Single

Returns comprehensive demographic information, insurance details, and emergency contacts for a single patient by UUID. Returns 404 if not found or soft-deleted.

POST /patients Create Patient

Creates and persists a new patient record. Validates past DOB, 10-digit U.S. phone numbers, 2-letter state codes, and 5-digit ZIPs. Persists to SQLite WAL and mirrors immediately to Supabase Cloud.

Sample Request Payload: {"first_name": "Eleanor", "last_name": "Vance", "date_of_birth": "1992-06-15", "sex": "Female", "phone_number": "5551234567", "address_line_1": "124 Hilltop Rd", "city": "Boston", "state": "MA", "zip_code": "02108"}
PUT /patients/{patient_id} Partial Update

Updates existing patient demographic fields. Supports partial updates (e.g. updating telephone or address only). Updates timestamps and syncs to Supabase.

DELETE /patients/{patient_id} Soft-Delete (Archive)

Soft-deletes a patient record by setting deleted_at timestamp in SQLite and Supabase. Record moves into the dashboard Archive Folder view.

POST /patients/{patient_id}/restore Restore Archived

Restores an archived patient record by clearing deleted_at = None. Returns patient record back to the Active Patients list.

DELETE /patients/{patient_id}/permanent Permanent Purge

Permanently deletes a patient record from both local SQLite storage and Supabase Cloud PostgreSQL. Cannot be undone.

GET /patients/export/csv CSV Stream
Download CSV 📥

Streams all patient demographic records as a CSV file attachment with UTF-8 BOM formatting for instant Microsoft Excel and Apple Numbers compatibility.

POST /patients/sync-supabase Cloud Sync

Forces an immediate bidirectional synchronization between local SQLite and Supabase Cloud. Purges locally any rows deleted in Supabase and pulls remote updates.

POST /voice/webhook Live Telephony

Inbound Vapi voice assistant webhook listener. Handles tool-calls from the LLM turn-taking pipeline, executing check_patient_by_phone, register_patient, update_patient, and end_call.

GET /voice/account-status Vapi Status

Returns the currently connected Vapi configuration status with masked credentials, configured Assistant ID, and assigned telephone number.

POST /voice/switch-account Account Switcher

Dynamically migrates the system to a new Vapi account by validating private/public keys, provisioning Alex with clinical tools, updating `.env`, and linking inbound phone numbers.

GET /health Health Check

Performs automated diagnostic health checks on FastAPI application status, SQLite database connectivity, and Supabase Cloud synchronization.
